# ArrayLab | JavaScript Logic & Array Exercises

[![Live Demo](https://img.shields.io/badge/Live_Demo-Open_Project-2563EB?style=for-the-badge&logo=vercel&logoColor=white)](https://javascript-array-playground.vercel.app/)

### Small challenges for practicing problem solving with JavaScript.

A collection of browser-based exercises covering number processing, strings, arrays, character matching, and a simple interactive board.

[![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=for-the-badge&logo=html5&logoColor=white)](https://developer.mozilla.org/en-US/docs/Web/HTML) [![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=for-the-badge&logo=javascript&logoColor=222)](https://developer.mozilla.org/en-US/docs/Web/JavaScript)

## 🧩 Exercises included

| Exercise | What it practices |
| --- | --- |
| 🔢 **Left-most digit** | Extract the first digit from a number. |
| ➕ **Number counter** | Count positive, negative, even, and odd values. |
| 🧹 **Filter integers** | Select integer values from entered array data. |
| ✂️ **Custom slice** | Recreate array slicing behavior with start and end indexes. |
| 📊 **Largest values** | Find the largest number in each nested array. |
| 🔤 **String abbreviation** | Shorten long strings while preserving the first and last characters. |
| 🔠 **Two kinds of characters** | Check whether a four-character string contains two distinct characters, each appearing twice. |
| ❌⭕ **Interactive board** | Practice DOM styling and click interactions on a 3×3 board. |
| 🔎 **Character positions** | Find all positions of a character in a word and report the first and last matches. |

## 🛠️ Built with

- HTML5
- JavaScript (vanilla)
- DOM APIs
- Browser prompts and form inputs

## ▶️ Run locally

~~~bash
git clone https://github.com/modewika1-star/t13.git
cd t13/code
~~~

Open `index.html` in a browser. The page contains multiple exercise examples, with some examples kept as commented HTML blocks. Enable the matching block and script when practicing a specific exercise.
